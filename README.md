# FlowPulse AI // Greater Bengaluru Kinetic Digital Twin (v3)

**Course:** Big Data Tools and Techniques  
**Coverage:** 32 Bengaluru Hubs • 54 Kinetic Corridors • 6 Zones • Namma Metro Overlays

## How to Run in VS Code (1-Click)
1. Extract this ZIP archive and open the inner `FlowPulse_AI_Bengaluru_BigData_Project` folder in **VS Code** (`File > Open Folder`).
2. Open **`run_project.py`** and click the **Run (`▶`)** button in the top-right corner (or press **`F5`**).
3. `run_project.py` automatically selects a free IPv4 port (`127.0.0.1:8000+`), launches the kinetic Google Maps dashboard in your browser, and streams live Bengaluru telemetry in the VS Code terminal.

## Signature UI/UX & Technical Upgrades in v3
- **Kinetic Corridor Photon Flows:** Animated SVG `stroke-dashoffset` traffic streams moving across all 54 Bengaluru corridors at velocities proportional to live corridor speed.
- **Bottleneck Sonar Shockwaves:** Expanding radar pulse rings around congested junctions (`<20 km/h`) and triggered incidents.
- **Horology Radial Load Chronometer:** Animated SVG circular load gauge with smooth cubic-bezier number tweening.
- **60Hz Stream Pulse Oscilloscope & Command Palette (`Ctrl+K`):** Live header telemetry waveform and instant keyboard search across all 32 Bengaluru hubs.
